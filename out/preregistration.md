# 사전 등록 (Pre-registration) — 직접 학습 vs 두 모델 비율

**작성 시각: 2026-08-30 13:22 KST (04:22 UTC)**
**이 문서는 실험을 실행하기 전에 작성되었다.** 결과를 본 뒤 예측을 수정하지 않는다.

---

## 검증하려는 반론

> "DeepHF는 이미 WT와 SpCas9-HF1의 효율을 각각 예측한다. 두 예측값을 나누면
> 활성 유지율이 나온다. 유지율을 직접 학습하는 것에 무슨 이득이 있는가?"

## 비교 대상

| 코드 | 방식 | 목표 변수 |
|---|---|---|
| **BASE** | 단일과제 모델 2개를 따로 학습 → 예측값의 비 `Ŷ_HF / Ŷ_WT` (상한 1.5) | 각각 WT 효율, HF1 효율 |
| **ST** | 단일과제 모델 1개가 유지율을 직접 학습 (= λ 스윕의 λ=0) | Y₂ |
| **MT** | 멀티태스크 모델의 Head B (= 본 논문의 λ=0.5 모델) | Y₂ (Y₁과 결합손실) |

## 공정성 조건 (기준선을 유리하게 두는 쪽으로 고정)

1. 세 방식 모두 **동일한 trunk 구조·동일 하이퍼파라미터**(AdamW, lr 2e-3, wd 1e-4,
   batch 256, max 60 epoch, patience 12, 코사인 감쇠)를 사용한다.
2. **동일한 Hamming≤3 연결성분 분할**을 사용한다. train/valid/test를 바꾸지 않는다.
3. BASE는 모델이 2개이므로 **파라미터 총량과 학습 연산량이 MT의 2배**다.
   이 이점을 상쇄하지 않는다.
4. 평가는 동일한 test set 5,394개, 동일한 정답(측정 Y₂, 상한 1.5 절단)에 대해 수행한다.
5. **Spearman ρ와 Pearson r를 모두 보고**하며, 어느 쪽이 유리하든 둘 다 싣는다.

## 사전 예측

### P1 — 전체 성능
**예측: MT > BASE.** 직접 학습이 전체 hold-out Spearman에서 앞선다.

*근거*: 비 R̂ = Ŷ_HF/Ŷ_WT의 상대분산은 두 예측 오차의 상대분산 합으로 근사된다.
독립 학습된 두 모델의 오차는 상쇄되지 않고 누적된다. 직접 학습은 이 오차를
직접 최소화한다. 또한 λ 스윕에서 결합 학습이 단독 학습보다 Y₂를 개선했다
(0.701 → 0.716)는 관측이 이미 있다.

**반증 조건**: BASE의 Spearman이 MT와 같거나 더 높으면 P1은 기각된다.

### P2 — 저효율 구간에서 격차가 최대 (핵심 예측)
**예측: 측정 WT 효율 하위 25% 구간에서 MT와 BASE의 격차가 가장 크다.**

*근거*: 분모가 작을 때 비율이 발산한다. test set에서 WT 1사분위는 0.609,
최소값은 0.018이다. 이 구간이 두 모델 방식의 구조적 취약점이다.

**반증 조건**: 사분위별 격차가 평탄하거나, 오히려 고효율 구간에서 더 크면 기각된다.

### P3 — 데이터가 적을수록 격차 확대
**예측: 학습 데이터를 10%로 줄이면 MT와 BASE의 격차가 커진다.**

*근거*: 각 모델의 예측 오차가 커지면 비율 계산에서의 오차 누적도 함께 커진다.
직접 학습은 유계(有界)인 목표를 학습하므로 상대적으로 덜 악화된다.

**반증 조건**: 10% 조건에서 격차가 유지되거나 축소되면 기각된다.

## 결과와 무관하게 유지되는 주장

P1–P3이 모두 기각되더라도 다음은 영향을 받지 않는다. 실험 결과에 논문 전체를
걸지 않기 위해 이를 명시해 둔다.

1. **전환 비용이 서열로 예측 가능한 형질이라는 사실 자체** (어느 추정기가 이기든
   보고된 바 없음). 학습하지 않은 eSpCas9에서 ρ = 0.492 (실측 간 상한 0.581의 85%).
2. **다목적 최적화 정식화** — 비지배 정렬, 파레토 전선 F₁ 26개.
3. **상충 보편성 반증** — 상위 5% 동시 만족 기대값 13.5 vs 실제 3.
4. **서열 문법 분리와 설계 규칙** — 위치 18 G→C가 두 목표를 동시에 개선,
   ISM 상위/하위 10개 치환 실측 대조 10/10 일치.

P1–P3이 기각되면 논문은 위 4개에 무게를 싣고, 기각 사실을 결과에 그대로 보고한다.
